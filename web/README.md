# CNtunyuan Web

全新 Web 管理端（Next.js + TypeScript），用于与现有后端 API 联调。

## 1. 启动

```bash
cd web
cp .env.example .env.local
npm install
npm run dev
```

默认地址：`http://localhost:3000`

## 2. 环境变量

- `NEXT_PUBLIC_API_BASE`：后端 API 基础地址，默认 `http://localhost:8080/api/v1`
- `NEXT_PUBLIC_WECHAT_WEB_APP_ID`：微信开放平台“网站应用”AppID（用于 Web 微信扫码登录）
- `NEXT_PUBLIC_WECHAT_WEB_REDIRECT_URI`：扫码回调地址（建议固定为 `https://你的域名/login`）

### Web 微信扫码登录配置说明

1. 在微信开放平台创建/配置“网站应用”（不是小程序应用）。
2. 获取网站应用 AppID（和 AppSecret），并在后端 `config.yaml` 中配置对应微信参数。
3. 将 `NEXT_PUBLIC_WECHAT_WEB_APP_ID` 配置为网站应用 AppID。
4. 将回调地址配置为同一个域名下的 `/login`，并在微信开放平台白名单中放行该回调域名。
5. Web 登录页会自动渲染微信扫码组件；扫码后微信回跳到 `/login?code=...`，前端调用后端 `/auth/wechat-web-login` 完成登录。

> 注意：若提示“该微信未绑定系统账号”，请先使用账号密码登录，再到“个人设置”执行微信绑定。

## 3. 当前实现范围

- 登录认证（账号密码 + 微信网页扫码登录）
- 工作台总览
- 案件中心（列表、筛选、快速建案、详情、状态操作、线索新增）
- 案件闭环动作（标记已找到/已团圆）
- 案件详情编辑（核心字段在线更新）
- 案件关联任务创建（从案件直接下发任务）
- 案件照片上传与绑定
- 任务中心（列表、筛选、快速建任务、详情、开始/完成/取消、跟进记录/审批）
- 任务中心高级能力（排序、全选/反选、批量分配/开始/完成/取消/删除、CSV导出）
- 任务高级创建页（执行人、优先级、截止时间、关联案件）
- 任务跟进详情（评论讨论、审批结果明细）
- 任务跟进附件上传（Web 端上传并随跟进提交）
- 方言中心（列表、筛选、快速创建、详情、审核、精选、评论管理）
- 组织管理（筛选、列表、组织树、创建、移动、删除、详情编辑、CSV导出）
- 人员管理（列表、筛选、创建、角色调整、激活/禁用、删除、批量操作、详情编辑、CSV导出）
- 审计中心（近期审计记录、时间/状态码检索、请求追踪、CSV导出）
- 工作台增强（待处理提醒、7/30天趋势分析）
- 统一交互（全站确认弹窗替换浏览器 confirm，统一操作提示条替换 alert）
- 文件管理中心（全量文件列表、筛选、预览、下载、删除）
- 网站设置（品牌信息、Logo、公告与联系方式配置，保存到后端数据库覆盖层）
- 功能设置（模块开关配置，前端本地持久化）
- 服务监控（health / detailed health / metrics 预览、运行环境与运行时信息）
- 个人设置（读取当前用户）

## 4. 说明

- 为保证与现有后端兼容，Web 端沿用小程序已验证的接口路径与字段。
- 若后端返回结构包含 `list` 或直接数组，前端会自动归一处理。
