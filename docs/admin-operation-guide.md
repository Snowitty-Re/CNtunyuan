# CNtuanyuan 管理员操作说明

本说明书面向管理员、组织负责人和超级管理员，帮助完成日常后台管理工作。

## 1. 管理员主要负责什么

管理员通常负责以下内容：

- 审批用户账号
- 管理用户与组织
- 管理案件和任务
- 审核方言录音
- 管理方言卡片
- 管理文件
- 查看操作记录
- 维护网站设置与功能开关
- 检查系统运行状态

## 2. 登录后台后建议先做的检查

每天首次登录后台时，建议先查看以下内容：

1. 工作台统计是否正常
2. 是否有待审批用户
3. 是否有待审核方言录音
4. 是否有异常任务或超期任务
5. 服务监控是否正常

## 3. 用户审批与账号管理

### 3.1 审批新用户

当新用户注册或通过快捷方式创建账号后，通常需要管理员审批。

操作步骤：

1. 进入“用户管理”
2. 筛选待审批用户
3. 打开用户详情
4. 核对姓名、手机号、组织、角色等信息
5. 通过或拒绝审批

建议：

- 先确认身份来源
- 不清楚的账号先不要通过
- 可先分配到合适组织后再启用

### 3.2 启用、禁用账号

适用场景：

- 人员离岗
- 账号异常
- 临时停用

停用前建议先确认：

- 该用户是否还有未完成任务
- 是否会影响当前案件处理

### 3.3 调整角色

管理员可根据实际职责调整角色。

常见原则：

- 志愿者：日常使用、采集、查看、处理分配任务
- 管理员：管理本组织或本范围内业务
- 超级管理员：系统级管理

请避免随意提升权限。

### 3.4 重置用户异常问题

常见问题包括：

- 用户无法登录
- 用户被停用
- 用户没有权限
- 用户组织不正确

处理时建议依次检查：

1. 账号是否已审批
2. 账号是否被禁用
3. 角色是否正确
4. 所属组织是否正确
5. 功能开关是否启用

## 4. 组织管理

### 4.1 新建组织

适用于新增地区、分组、分站点时。

建议填写完整：

- 组织名称
- 组织编码
- 上级组织
- 联系人
- 联系方式

### 4.2 调整组织归属

当人员或业务范围变化时，可调整组织归属。

请注意：

- 组织变更会影响数据权限范围
- 上级组织通常拥有下级组织范围内的管理权限

### 4.3 日常组织维护建议

- 组织名称保持统一规范
- 不重复创建近似组织
- 组织编码尽量固定

## 5. 案件管理

### 5.1 日常检查重点

管理员建议重点关注：

- 新增案件是否信息完整
- 长时间未更新案件
- 状态异常的案件
- 联系方式不完整的案件

### 5.2 修改案件状态

修改案件状态前建议确认：

- 是否有最新跟进依据
- 是否已联系相关人员
- 是否会影响后续任务安排

### 5.3 删除案件

删除案件应当谨慎。

建议仅在以下场景删除：

- 明显误录
- 重复创建
- 管理确认无需保留

如果只是业务结束，通常更建议更新状态，而不是直接删除。

## 6. 任务管理

### 6.1 创建与分派任务

创建任务时建议明确写清：

- 任务目标
- 完成要求
- 截止时间
- 执行地点
- 关联案件
- 执行人

### 6.2 跟踪任务进度

管理员可通过任务列表和详情关注：

- 是否已分派
- 是否开始执行
- 是否超期
- 是否提交反馈
- 是否已完成

### 6.3 常见管理建议

- 截止时间不要过于宽泛
- 一项任务尽量对应一个明确目标
- 对重要任务及时催办和复核

## 7. 方言录音审核与卡片管理

### 7.1 审核方言录音

管理员审核时建议重点关注：

- 是否按卡片要求完整录制
- 音频是否清晰
- 地区信息是否合理
- 采集地址是否准确
- 地图点位是否正确

### 7.2 驳回时怎么写意见

意见建议尽量具体，例如：

- 某张卡片未录制
- 背景噪音过大
- 地区填写不完整
- 位置选择错误

不要只写“有问题”这类模糊内容。

### 7.3 方言卡片管理

管理员可以：

- 创建分组
- 上传卡片图片
- 设置卡片名称
- 调整分组下卡片内容
- 删除不再使用的卡片

建议：

- 卡片名称简洁明确
- 图片尽量清晰
- 同一分组保持主题一致

## 8. 文件管理中心

文件管理中心用于统一管理系统上传文件。

管理员可进行：

- 查看文件
- 预览图片
- 下载文件
- 删除无效文件

注意：

- 删除文件前先确认是否仍被案件、任务或方言录音使用
- 大文件较多时建议定期清理

## 9. 审计记录与问题排查

审计中心适合排查以下问题：

- 谁修改了某条数据
- 谁删除了某个内容
- 某时间段发生了哪些关键操作

建议按以下条件筛选：

- 操作人
- 时间范围
- 模块名称
- 操作类型

## 10. 网站设置与功能设置

### 10.1 网站设置

通常用于维护：

- 网站名称
- Logo
- 域名
- 默认组织名称
- 默认组织编码

修改后建议刷新前台页面确认是否生效。

### 10.2 功能设置

功能设置通常用于控制：

- 是否开放注册
- 是否启用小程序快捷登录
- 是否启用 Web 扫码登录

修改前建议先确认业务影响。

例如：

- 关闭注册后，新用户将无法自行注册
- 关闭某种登录方式后，对应入口会隐藏

## 11. 服务监控

服务监控主要用于查看运行状态。

重点检查项：

- 数据库状态
- 缓存状态
- 服务状态
- 运行环境信息

如果显示异常：

- 先不要大规模操作数据
- 及时联系技术人员

## 12. 初始化流程

首次部署后，系统可能需要初始化。

通常包括：

- 配置数据库
- 配置站点信息
- 创建超级管理员

初始化完成后，建议立即：

1. 修改超级管理员密码
2. 检查网站设置
3. 检查功能设置
4. 新建组织结构
5. 创建管理员账号

## 13. 日常管理建议

建议管理员建立固定巡检习惯，例如：

- 每天查看待审批用户
- 每天查看待审核录音
- 每天查看异常任务
- 每周清理无用文件
- 每周抽查审计记录
- 每次重大调整后确认功能开关

## 14. 常见问题处理建议

### 14.1 用户说看不到菜单

请检查：

- 该用户角色
- 该用户组织
- 是否已启用账号
- 对应功能是否已关闭

### 14.2 用户说登录不上

请检查：

- 账号是否审批通过
- 账号是否被禁用
- 登录方式是否启用

### 14.3 用户说数据不对

请检查：

- 是否查看了错误组织范围
- 是否筛选条件未清空
- 是否刚修改但页面未刷新

### 14.4 删除后找不到数据

先确认是：

- 被删除
- 被禁用
- 被移动组织
- 被状态筛选隐藏

## 15. 管理员工作原则

- 审批要谨慎
- 删除要慎重
- 角色授权要最小化
- 重要变更先确认影响范围
- 出现异常先保留现场信息，再联系技术支持
