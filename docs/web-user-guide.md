# CNtuanyuan Web 端使用说明

本说明书面向日常使用人员，不需要技术背景。

## 1. Web 端适合谁使用

Web 端主要用于日常管理和后台处理，适合：

- 超级管理员
- 管理员
- 组织负责人
- 需要进行审核、配置、查看统计的工作人员

如果您主要是日常采集线索、提交录音、查看任务，通常更适合使用小程序。

## 2. 登录系统

### 2.1 登录方式

系统可能支持以下方式：

- 账号密码登录
- 微信扫码登录

实际显示哪种方式，以系统当前配置为准。

### 2.2 首次登录后建议做的事

首次登录后，建议先检查以下内容：

- 修改自己的密码
- 检查姓名、头像、联系方式是否正确
- 确认自己所属组织是否正确

## 3. 首页与工作台

登录后通常首先进入工作台或仪表盘，您可以看到：

- 案件数量
- 任务数量
- 方言录音数量
- 审核进度
- 近期数据趋势

这部分主要用于快速了解当前整体情况。

## 4. 案件管理

案件用于记录走失人员相关信息。

### 4.1 查看案件

进入“案件管理”后，您可以：

- 查看案件列表
- 按状态筛选
- 搜索姓名、地区等信息
- 打开案件详情查看完整资料

### 4.2 新建案件

新建案件时，通常需要填写：

- 走失人员姓名
- 年龄或大致年龄
- 性别
- 走失地区
- 详细描述
- 联系方式
- 相关图片

填写完成后提交即可。

### 4.3 更新案件

在案件详情中，您可以根据权限：

- 修改案件信息
- 更新案件状态
- 补充跟进记录
- 查看地图位置

### 4.4 删除案件

删除前请确认该案件确实不再需要。

删除后通常无法直接恢复。

## 5. 任务管理

任务用于把具体工作分配给具体人员。

### 5.1 任务列表

在“任务管理”中，您可以看到：

- 待处理任务
- 进行中任务
- 已完成任务
- 已取消任务

### 5.2 创建任务

创建任务时通常需要填写：

- 任务标题
- 任务说明
- 截止时间
- 执行人
- 关联案件
- 执行地点

### 5.3 处理任务

根据权限，您可以：

- 指派任务
- 开始执行
- 填写反馈
- 上传现场照片或附件
- 完成任务

## 6. 方言录音管理

方言模块用于采集和管理方言语音资料。

### 6.1 方言录音列表

您可以：

- 查看录音列表
- 按地区筛选
- 按状态筛选
- 播放录音
- 查看详情

### 6.2 方言卡片

系统使用“方言卡片”指导录入内容。

卡片通常包含：

- 显示名称
- 配图
- 所属分组

录音采集时，需要按照卡片顺序完成全部内容。

### 6.3 审核方言录音

有审核权限的人员可在审核页面：

- 收听录音
- 查看录入信息
- 审核通过
- 审核驳回
- 填写审核意见

## 7. 用户与组织管理

### 7.1 用户管理

在“用户管理”中，您可以：

- 查看用户列表
- 搜索用户
- 查看用户详情
- 审批新用户
- 启用或禁用账号
- 调整角色
- 调整所属组织

### 7.2 组织管理

在“组织管理”中，您可以：

- 查看组织结构
- 新建组织
- 编辑组织
- 分配组织负责人

请注意：权限通常与组织层级有关。上级组织可以管理下级组织范围内的数据。

## 8. 文件管理

文件管理中心用于统一查看系统内上传的文件。

您可以：

- 查看文件列表
- 预览图片
- 查看文件名称、大小、上传时间
- 下载文件
- 删除无用文件

删除文件前请确认该文件不再被业务使用。

## 9. 审计记录

审计中心用于查看系统操作记录。

您可以按以下条件查询：

- 操作人
- 操作时间
- 操作类型
- 业务模块

适合用于排查“谁在什么时间做了什么操作”。

## 10. 网站设置与功能设置

### 10.1 网站设置

可配置内容通常包括：

- 网站名称
- 网站 Logo
- 域名
- 默认组织名称
- 默认组织编码

修改后，部分页面显示会同步更新。

### 10.2 功能设置

可控制系统功能开关，例如：

- 是否开放注册
- 是否启用小程序快捷登录
- 是否启用 Web 扫码登录

如果某项功能关闭，对应登录入口或业务入口会自动隐藏。

## 11. 服务监控

服务监控用于查看系统运行状态，常见信息包括：

- 服务是否正常
- 数据库状态
- 缓存状态
- 运行环境

如果这里显示异常，请联系管理员或技术人员处理。

## 12. 初始化页面

首次部署系统后，可能需要先完成初始化。

初始化通常包括：

- 配置数据库
- 配置站点信息
- 创建超级管理员

普通用户一般不需要进入该页面。

## 13. 常见问题

### 13.1 登录后提示无权限

可能原因：

- 您的账号尚未审批
- 您的角色权限不足
- 您所属组织不在该数据范围内

请联系管理员确认。

### 13.2 登录后提示已过期

通常是登录状态失效，请重新登录。

如果反复出现，请联系管理员。

### 13.3 找不到某个功能入口

可能原因：

- 当前角色没有该权限
- 该功能已被系统关闭
- 当前账号不在对应组织范围内

### 13.4 上传文件失败

请先检查：

- 网络是否正常
- 文件大小是否过大
- 文件格式是否受支持

## 14. 使用建议

- 重要信息提交前先核对
- 删除操作前再次确认
- 审核时尽量填写明确意见
- 不要将账号密码随意告知他人
- 离开电脑前及时退出登录

## 15. 需要帮助时

如果您在使用中遇到问题，请优先记录以下信息再联系管理员：

- 出问题的页面名称
- 您刚刚执行了什么操作
- 报错提示内容
- 问题发生的大概时间

这样可以更快定位问题。
