## 3. 系统由哪些部分组成

CNtuanyuan 项目通常由两部分组成：

### 3.1 Web 端

主要用于：

- 后台管理
- 用户与组织管理
- 案件与任务管理
- 方言录音审核
- 系统设置
- 文件管理
- 审计记录
- 服务监控

### 3.2 小程序端

主要用于：

- 日常登录使用
- 查看案件
- 处理任务
- 地图查看
- 方言录制
- 提交反馈
- 修改个人资料

## 4. 建议的使用分工

为了提高管理效率，建议按以下思路分工：

- 超级管理员：负责系统总配置与全局管理
- 管理员：负责本范围内业务管理和审批
- 志愿者或普通工作人员：负责日常采集、查看和处理任务

## 5. 项目上线后的基本使用顺序

建议按以下顺序开始使用：

1. 管理员登录 Web 端
2. 检查网站设置与功能设置
3. 建立组织结构
4. 创建或审批管理员账号
5. 创建或审批普通用户账号
6. 通过 Web 端和小程序开始日常业务使用

## 8. 常见业务流程

### 8.1 新用户启用流程

通常流程如下：

1. 用户注册或快捷创建账号
2. 管理员在后台查看待审批用户
3. 管理员审核通过
4. 用户正式登录使用

### 8.2 案件处理流程

通常流程如下：

1. 新建案件
2. 补充案件信息
3. 分配相关任务
4. 志愿者执行并反馈
5. 管理员更新案件状态

### 8.3 方言录制流程

通常流程如下：

1. 用户进入方言录制页面
2. 按卡片要求完成全部录音
3. 填写地区、地址和位置
4. 提交录音
5. 管理员审核

## 10. 建议的交付后管理方式

建议项目交付后指定固定负责人：

- 业务负责人：负责业务流程
- 系统管理员：负责账号、组织、权限与配置
- 日常使用人员：负责录入、查看、跟进和反馈

这样可以减少职责混乱。

## 11. 出现问题时怎么反馈

无论是 Web 端还是小程序，建议反馈时提供以下信息：

- 使用的是哪个端
- 打开的页面名称
- 做了什么操作
- 出现了什么提示
- 问题发生的大概时间

如有截图，建议一并提供。

## 12. 交付建议

建议在正式投入使用前，组织一次简短培训，至少覆盖：

1. 登录与账号审批
2. 案件与任务基本流程
3. 方言录制与审核
4. 用户与组织管理
5. 常见问题处理方式
