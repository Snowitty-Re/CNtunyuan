# 小程序手机号收集合规说明（内部使用）

供微信审核与运营自查。依据《关于小程序收集用户手机号行为的规范》中「企业内部使用」指引。

## 产品定位

- **名称**：助力团圆 · 志愿者内部协作端  
- **使用人群**：已认证志愿者、组织管理人员  
- **使用场景**：寻亲案件协作、任务跟进、方言采集等**内部工作**  
- **非目标用户**：请勿注册；可在说明页选择退出  

## 未登录可见内容

- 仅 **内部使用说明页**（`pages/welcome/index`）  
- **不展示**案件列表、人员名单、任务、轨迹等业务数据  

## 登录与手机号

1. 用户主动点击「志愿者登录」后进入登录页  
2. 主路径为 **微信登录**（不强制一进小程序就要手机号）  
3. 微信登录后若未绑定真实手机号：  
   - 须「授权手机号并绑定」后方可使用业务功能  
   - 可选择「**暂不绑定，返回说明页**」或「**我不是志愿者，退出**」  
   - 拒绝 `getPhoneNumber` 后仅可继续绑定或返回说明页，**不可进入业务 Tab**，**不反复弹窗**  
4. **全部业务 API**（与后端一致）要求账号 **active + 真实大陆手机号**；未完成则引导绑定或退出  

## 提审材料建议

1. 录屏：打开 → 说明页 → 登录 → 暂不绑定 → 进首页 → 点任务被拦截 → 绑定成功 → 可看任务  
2. 截图：说明页、登录页、绑定页（含拒绝/退出按钮）  
3. 体验账号：已审批志愿者手机号 + 密码  

## 体验账号（示例，以实际环境为准）

见项目 `AGENTS.md` 默认管理员账号，或初始化向导创建的超管账号。
